# 트레이딩 시스템 빠른 참조 가이드

> 운영 중 빠르게 확인해야 할 핵심 정보

---

## 모드 상태

| 모드 | 상태 | 신규 진입 | 청산 | 복구 |
|------|------|----------|------|------|
| **NORMAL** | 정상 | ✅ 허용 | ✅ 허용 | - |
| **SAFE** | 경계 | ❌ 금지 | ✅ 허용 | 자동 |
| **HALT** | 중지 | ❌ 금지 | ✅ 허용 | 수동 |

---

## 핵심 한도

### 손실 한도
```
일일: -1.5% → SAFE, -3.0% → HALT
주간: -5.0% → Satellite 비활성화
```

### 노출 한도
```
총 노출: 120%
Core 심볼당: 10%
Satellite 심볼당: 3%
```

### 슬리피지 한도
```
Core: 6 bps
Satellite: 15 bps
```

---

## 전략 진입 조건

### Core (Cash & Carry)
```
✓ Net Edge ≥ 0.20%
✓ 유동성 필터 통과
✓ 레짐 = BULLISH 또는 NEUTRAL
✓ NORMAL 모드
```

### Satellite (모멘텀)
```
Phase 1:
✓ RVOL_5m ≥ 2.5
✓ Close > 12봉 고점
✓ Close ≥ VWAP
✓ ClosePos ≥ 0.75

Phase 2 (다음 봉):
✓ 돌파 레벨 유지
✓ 거래량 유지
```

## 청산 조건

### Core
| 조건 | 기준 |
|------|------|
| Edge 수렴 | ≤ 0.05% |
| 펀딩 손실 | > 1% |
| 헤지 오류 | > 0.5% |

### Satellite
| 조건 | 기준 |
|------|------|
| 하드 손절 | -0.8% |
| 트레일링 | +1% 후 0.6% |
| 타임스톱 | 30분 |
| 레짐 악화 | VOLATILE |

---

## 유동성 필터

```
✓ 24h 거래대금 ≥ 50M USDT
✓ 스프레드 ≤ 8 bps
✓ 오더북 깊이 ≥ 주문량 × 5
```

---

## SAFE 트리거 (주요)

| 조건 | 기준 |
|------|------|
| WS 지연 | > 2초 × 10초 |
| 주문 실패율 | > 20% / 60초 |
| 일 손실 | -1.5% |
| ATR 급증 | 1.8배 + 급락 |

## HALT 트리거 (주요)

| 조건 | 기준 |
|------|------|
| Reconcile 실패 | 불일치 감지 |
| 일 손실 | -3.0% |
| 청산 거리 | < 2.5% |

## 헤지 실패 대응

```
2. IOC 시장가 주문
3. 실패 시 Spot 롤백
4. SAFE 모드 전환
```

## 긴급 상황 대응

### 청산 위험 시
1. 즉시 HALT 모드 전환
2. 포지션 수동 확인
3. 필요 시 마진 추가

### 헤지 불일치 시
1. Reconciler 로그 확인
2. 거래소 포지션 직접 확인
3. 수동 정리 후 재시작

### WS 끊김 시
1. 자동 재연결 대기 (10초)
2. SAFE 모드 자동 전환
3. 연결 복구 후 NORMAL
