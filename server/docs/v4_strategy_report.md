## 개요

### 목표

v3.3 최적화 3개 전략(VOB, CR, TBR)에 v4 신규 전략을 추가하여 멀티전략 복합 백테스트 시스템 구축.

### 진행 과정

| 단계 | 설명 | 결과 |
|------|------|------|
| v4.0 초기 | 7개 전략 (v3 3개 + v4 4개) 마진모드 | +127.28% (30일) |
| v4.0 반복 | 9회 반복 최적화 (마진모드 도입) | +127.28% → 안정화 |
| 데이터 분석 | 760건 거래 패턴 심층 분석 | RSI/ATR/시간대 핵심 인사이트 |
| v4.1 고도화 | 하위 3개 전략 삭제, 상위 4개 데이터 기반 업그레이드 | +152.40% (마진, 30일) |
| 실투자 시뮬 | 현금 기반 현실적 시뮬레이션 | +27.4% (30일), +26.8% (90일) |

## 아키텍처

### 복합 전략 인프라

```
CombinedSignalGenerator          CombinedExitChecker
├── VOB SignalGenerator          ├── VOB exit (SL/TP/Trail/TimeStop)
├── CR SignalGenerator           ├── CR exit
├── TBR SignalGenerator          ├── TBR exit
└── VSR SignalGenerator          └── VSR exit
         │                                │
         ▼                                ▼
   점수 내림차순 정렬              position.strategy 기반 라우팅
   (고확신 시그널 우선)            (전략별 다른 청산 파라미터)
```

### 핵심 엔진 변경 (backtest_engine.py)

| 변경 | 설명 |
|------|------|
| `strategy` 필드 버그 수정 | `signal.get("strategy")` 사용으로 전략별 포지션 구분 |
| multi_strategy 키 | `strategy:symbol` 형태로 동일 심볼 다중 전략 포지션 허용 |
| margin_mode | 초기자본 기준 고정 사이즈 (전략별 독립 운용) |
| 현금 기반 모드 | `equity * position_pct`, `cash * 0.95` 상한 |

## 데이터 분석 기반 고도화 (v4.1)

### 분석 방법

`analyze_v4_trades.py`로 760건 거래 데이터 심층 분석:
- 전략별 승리/패배 거래 진입 지표 비교
- 시간대별(KST) 승률 분포
- 보유시간별 성과
- TP/SL 도달 시간
- SL 거래의 최대 수익 도달 분석

### 핵심 인사이트

#### 1. RSI 분포와 승률

| RSI 구간 | 거래수 | 승률 | 판단 |
|----------|--------|------|------|
| 0-20 | 280건 | **68.9%** | 최고 |
| 20-25 | 171건 | **66.1%** | 우수 |
| 25-30 | 209건 | 53.6% | 보통 |
| 30-35 | 38건 | **34.2%** | 손실 |

**결론: RSI < 25가 황금 구간. 25 이상은 품질 급감.**

#### 2. ATR% 분포와 승률

| ATR% 구간 | 거래수 | 승률 | 판단 |
|-----------|--------|------|------|
| 1.0-1.5% | 286건 | 54.9% | 낮음 |
| 1.5-2.0% | 110건 | **77.3%** | 최고 |
| 2.0-3.0% | 75건 | **72.0%** | 우수 |
| 3.0-5.0% | 10건 | 60.0% | 양호 |

**결론: ATR > 1.5%가 핵심 조건. 1.0-1.5%는 승률 22%p 하락.**

#### 3. 시간대별 승률 (KST)

| 시간 | VOB | CR | TBR | VSR |
|------|-----|-----|-----|-----|
| **09시** | **95.0%** | **78.3%** | **73.2%** | **93.3%** |
| 12시 | 100% | 81.2% | 84.6% | - |
| 00시 | 62.5% | 68.8% | 76.9% | 12.5% |
| **02시** | **33.3%** | **7.1%** | **3.7%** | **14.3%** |

**결론: 09시(KST) 전략 최고 시간대, 02시는 재앙 (거의 100% 손실).**

#### 4. 보유시간별 성과

| 보유시간 | TBR 승률 | VOB 승률 |
|----------|----------|----------|
| 0-15분 | **72.0%** | **81.5%** |
| 15-30분 | **70.5%** | **90.9%** |
| 30-60분 | 43.1% | 75.0% |
| 1시간+ | 42-46% | 25-67% |

**결론: 빠른 청산이 유리. 30분+ 보유 시 성과 급감.**

#### 5. TBR 트레일링 문제

- SL로 청산된 거래 중 **14%(22건)가 +1% 이상 수익을 달성한 후 반전**
- 기존 trailing_trigger 2.0%는 너무 높아 이 거래들을 잡지 못함
- **trailing_trigger를 1.2%로 낮추면 이들을 구제 가능**

### 수익률 한계의 본질

30일 +26% vs 90일 월평균 +8.7% 차이 원인:

```
90일 구간 분석:
├── 11/27 ~ 01/08  (40일): 데이터 없음, 거래 0건
├── 01/08 ~ 01/25  (18일): 횡보/하락 → -3.2% 최대낙폭
└── 01/26 ~ 02/07  (13일): 대형 급락반등 → 수익 폭발 (+26%)
    └── 02/06 주간 단독: +100K (전체 수익의 ~40%)
```

- 이 전략은 **큰 급락→반등** 장에서 수익 극대화
- 횡보/완만한 하락장에서는 수익 미미 또는 소폭 손실
- **월 +8.7% (연 +171%)가 현실적 평균 기대치**
- 참고: 워렌 버핏 연평균 ~20%, 세계 최고 헤지펀드 ~30-40%
